자주 묻는 질문

페이지 수가 나눠떨어지지 않으면 어떻게 되나요?

마지막 장에 빈 칸이 남는 형태로 처리됩니다. 예: 5페이지를 2-up으로 모으면 3장이 되고, 마지막 장 하나는 빈 칸으로 남습니다.

텍스트를 편집·검색할 수 있나요?

변환 과정에서 페이지가 이미지로 바뀌므로, 결과 PDF에서는 텍스트 선택·검색이 되지 않습니다.

파일이 서버에 업로드되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 파일은 서버로 전송되지 않습니다. 완전히 안전합니다.
