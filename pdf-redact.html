자주 묻는 질문

검은 박스 아래 글자가 나중에 복사·추출될 수 있나요?

아니요. 이 도구는 박스로 덮기만 하는 게 아니라 해당 페이지를 이미지로 다시 만들어 원본 텍스트 자체를 제거합니다. 드래그로 복사하거나 텍스트 추출을 해도 가려진 내용은 나오지 않습니다.

주민등록번호·계좌번호를 가리는 데 적합한가요?

네. 개인정보가 포함된 서류를 외부에 제출·공유하기 전 민감 정보를 완전히 지우는 용도로 설계됐습니다.

박스를 그리지 않은 페이지는 어떻게 되나요?

가림 표시를 하지 않은 페이지도 이미지로 변환되어 저장됩니다. 문서 전체의 텍스트 검색·복사 기능은 사라집니다.

가린 부분을 실수했을 때 되돌릴 수 있나요?

저장 전에는 박스를 옮기거나 삭제할 수 있지만, 저장 후에는 복구할 수 없습니다. 원본은 반드시 따로 보관하세요.

가린 뒤 파일 용량이 커졌어요.

페이지가 이미지로 바뀌면서 용량이 늘 수 있습니다. 제출 규격이 있으면 PDF 압축 도구로 줄이세요.

파일이 서버에 업로드되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 파일은 서버로 전송되지 않습니다. 개인정보와 민감한 데이터가 외부로 유출될 걱정이 없으며, 기업 보안 환경에서도 안심하고 사용할 수 있습니다.
