Frequently Asked Questions

Does this work with any PDF?

No. It only works with PDFs that already contain fillable AcroForm fields. For scanned or image-only PDFs, use the free-placement PDF Editor instead.

Are checkboxes and dropdowns supported?

Yes. Text fields, checkboxes, and dropdown selection fields are all detected and can be filled in.

Is my file uploaded to a server?

No. All processing happens entirely in your browser. Your file is never sent to any server.
