Frequently Asked Questions

Does cropping reduce quality?

No. Text and images stay exactly as the original — only the visible area of the page shrinks. There is no quality loss.

Is the same margin applied to every page?

The top/bottom/left/right margins you set are applied to all pages. For documents with varying margins, use the largest margin to be safe.

Can I remove the black border left by scanning?

Yes. Pull the edges inward with the sliders to cut off scan shadows or black bands.

I want to reduce margins to fit an e-reader screen.

Smaller margins make the body text larger on tablets and e-readers. Crop first, then use the page-size tool to match the screen ratio.

Does the file size go down too?

Only the visible area changes, so the size barely moves. Use the compression tool to reduce size.

Are my files uploaded to a server?

No. All processing happens entirely inside your browser and your files are never sent to a server. There is no risk of personal or sensitive data leaving your device, so it is safe to use even in a corporate environment.
