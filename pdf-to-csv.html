  • 여러 페이지의 표 데이터도 한 번에 추출됩니다.

자주 묻는 질문

어떤 PDF를 변환하면 좋은 결과를 얻나요?

표가 명확하게 구분된 텍스트 기반 PDF에서 최적의 결과를 얻습니다. 스캔 이미지 PDF는 텍스트 레이어가 없어 추출이 어렵습니다.

CSV 파일을 엑셀에서 열려면?

다운로드한 CSV 파일을 Excel에서 파일 열기로 불러오세요. 한글이 깨질 경우 인코딩을 'UTF-8 BOM'으로 선택 후 다시 변환하세요.

여러 페이지의 데이터는 어떻게 되나요?

각 페이지의 데이터가 순서대로 CSV에 합쳐집니다. 페이지 구분선이 포함되어 구분하기 쉽습니다.

파일이 서버에 저장되나요?

아니요. 모든 처리는 브라우저 안에서만 이루어지며 파일은 서버로 전송되지 않습니다. 개인정보와 민감한 데이터가 외부로 유출될 걱정이 없으며, 기업 보안 환경에서도 안심하고 사용할 수 있습니다.
